Class 50: Negative & Interrogative

Present Simple Rules

📖 Negative Sentences (Don't / Doesn't)

To make a negative sentence, use do not (don't) or does not (doesn't) + base verb.

  • I / You / We / They + don't + verb. (e.g., I don't like coffee.)
  • He / She / It + doesn't + verb. (e.g., She doesn't like coffee.)

❓ Interrogative Sentences (Do / Does)

To ask a question, put Do or Does at the beginning.

  • Do + I / you / we / they + verb? (e.g., Do you like coffee?)
  • Does + he / she / it + verb? (e.g., Does she like coffee?)
